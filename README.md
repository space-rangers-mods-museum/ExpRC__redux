# 🗄️ redux__ExpRC

* **Name:** redux__ExpRC
* **Author:** Huk, Klaxons

### Summary

Warning! Untranslated staff! Expands the capabilities of Ranger Centers

---

## 📖 Description

Expanding the functionality of ranger centers:

- The player has a personal storage of micromodules, which can be accessed at any CR

- New Year's gift micromodules are automatically moved to this storage

- The old mechanics of pseudo-random issuance of MM in RC for nodes has been returned, as in SR2

- If all CRs are destroyed, access to the storage is lost along with all micromodules hidden in it

- All questions about rangers, nodes and pirates on the RC have been moved to a separate dialogue

Adding new game mechanics:

- The player can collect unknown micromodules that occasionally drop out of dominators

- Unknown MMs are handed over to the RC for a substantial reward, and for every 25 unknown MMs the player is awarded a special experimental micromodule
